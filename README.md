Project: Shared Bookmarks

A webpage where users can save ,view,like , and copy bookmarked links.

Features:
-Select a user from a dropdown
-View bookmarks for the selected user
-Add a new bookmark with a URL ,title,description, timestamp
-Copy a bookmark URL to the clipboard
-Like bookmarks
-Data persists in the browser using local storage

How to run the project:
-Locally
   -open the project using local server, like VS Code lie server
-Live:
   -   https://shared-bookmarks-ping-and-alex.netlify.app/

How to run tests:
-Instal Node.js
-run npm install
-run npm test
